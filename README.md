# BoardGames Web App

Aplikacja webowa BoardGaming.

## Wymagania

- Node.js 18+
- npm

## Uruchomienie

```bash
npm install
npm start
```

Aplikacja dostępna pod `http://localhost:3000`.

## Dane demo

- Email: `demo@example.com`

## Technologie

- React 18
- react-router-dom v6
- CSS Variables (zgodne z oryginalną paletą UIColors.xaml)

## Paleta kolorów (z UIColors.xaml)

- Tło: `#0A003A` / `#1C0E49`
- Akcent główny: `#6D2FFF` (fioletowy)
- Złoty: `#FFC047`
- Cyan: `#4ADAEC`
- Różowy: `#FB539B`
